上一篇[《一片草地的诞生》](/pixel-grass/)解释了草片、风动和云影。这一次保留同样的草坪与贴图，在上面放置三块不同高度的立方体，观察它们的影子怎样落在地面与动态草叶上。

这篇文章的主线是：**先判断光有没有被挡住，再决定这份光怎样变成像素风的明暗。** 各阶段共用同一套布局；切换按钮后，下面的说明与实际运行代码会同步变化。

{{< grass-step number="1" title="基准：背光面与投影是两回事" >}}

**本步状态：草坪、立方体、小球都有表面的明暗，但尚未接收物体投影。** 原有的色块、风动、分帧和角色拨草继续运行，云影暂时关闭，便于集中观察真实遮挡。

把相机转到立方体另一侧，你仍能看到有些面亮、有些面暗。这来自表面朝向与光线方向的关系，并不能说明已经实现了阴影。要出现投影，还必须知道：这个接收点与太阳之间，有没有别的物体。

### 场景里放了什么

三块立方体分别提供较宽、较矮和较高的遮挡。它们的位置在所有阶段都保持一致；小球沿草坪前方的固定路线运动，用于检查移动投影和拨草。

这段代码同时为立方体建立了两种表示：主场景中的彩色网格，以及只供光源视角记录深度的遮挡网格。它们共享几何形状和位置。草叶与地面没有加入遮挡场景，因此后续只接收投影，不会互相投影。

### 复用的贴图

{{< grass-textures names="grassleaf,accentleaf,patch-a,patch-b,wind" >}}

普通草和装饰草使用上一文的两张透明贴图，色块使用同样的两张固定噪声，风场也沿用同一张噪声。此时尚未把任何阴影纹理乘到颜色上。

**观察方式：** 调整太阳方向和高度，检查立方体各面的明暗变化。注意底板上还没有它们的投影。这里从一开始就使用可关闭的直射光，不保留上一文手工光照中的固定最低亮度；环境光要到第六步才加入。

**本步新增：立方体和小球的阴影先落到底板上。草叶暂不接收。** 密集草叶可能遮住底板上的影子，取消「显示草叶」可以直接观察这一层。

### 怎样从世界位置找到深度图上的位置

太阳方向既用于光照，也用于放置光源相机。下面的矩阵把世界坐标依次转换成光源视图坐标、裁剪坐标，最后映射到纹理所用的 0～1 范围。

同一个接收点在深度图上查到的数值，代表太阳沿这个方向最先遇到的表面。如果接收点自身的深度更远，就说明它位于遮挡物后面。

{{< grass-code demo="grass-shadows" file="lighting.glsl" region="depth-compare" lang="glsl" >}}

这里用九次深度比较结果的平均值实现 PCF：0 表示全遮挡，1 表示完全可见，中间值形成过滤后的边缘。平均的是**比较结果**，并非先把深度值混合，再比较一次。默认使用一像素的采样间距，第七步可以调节。

斜面上的相邻采样点自身深度也会变化，因此代码用屏幕导数估算接收面的深度斜率，修正各个样本的比较值。否则，立方体斜对着光源的一面可能错误地遮挡自己，出现细碎条纹；这与草叶的分帧动画无关。

**本步的新纹理：光源深度图。** 它由场景实时生成，不是手绘黑色贴图，也不是云影噪声。展开演示下方的深度图：近处较黑，远处较白；空白区域的深度为 1。移动观察相机不改变光源视角，移动太阳才会改变这张图。
{{< grass-step-end >}}

{{< grass-step number="3" title="接收：让草叶也参与遮挡判断" >}}

**本步新增：草叶开始读取与底板相同的阴影贴图。** 如果只给底板加阴影，草叶仍然输出自己的亮颜色，就会把底板上的投影盖住，形成“有阴影，但草还在发亮”的效果。

为了单独看清接收机制，这一步先采用一个近似：每撮草都用自己的根部位置查询阴影。整撮草因此取得同一个遮挡值。下一步再解决这个位置近似带来的问题。

{{< grass-code demo="grass-shadows" file="lighting.glsl" region="receiver-position" lang="glsl" >}}

`isGrass` 区分叶片与其他表面：第二步只让地面和立方体接收，第三步开始让叶片参与。地面使用连续的表面位置，草暂时使用根部。只开启材质上的一个接收标记，不会自动让完全自定义的片元代码学会使用阴影，必须把这个可见度值接入最终光照。

### 贴图怎样组合

```text
色块噪声 → 草根所在区域的底色
草叶贴图 → 叶片轮廓
光源深度图 → 这个位置的光线可见度
                         ↓
                   底色 × 受光结果
```

原有底色、草叶 UV 与风噪声保持各自职责。阴影只改变受光强度，不改草的形状，也不重新生成草的颜色分布。

**观察方式：** 选择「查看阴影遮罩」，白色表示可见，黑色表示被挡住；这是诊断画面，不受环境光和太阳强度影响。开启「对比上一步」，可以看到原本没有接收阴影的叶片开始一起变暗。
{{< grass-step-end >}}

{{< grass-step number="4" title="位置：阴影必须跟着变形后的叶片走" >}}

**本步新增：草叶使用风动、拨草之后的真实表面位置查询阴影。** 根部取色仍然保留；取色位置与阴影位置不必相同。

一撮草的根部可能在光里，草尖却伸进了立方体的影子。如果整撮草只查询根部，草尖就会错误地保持明亮；反过来，根部被挡住时，已经伸出阴影的草尖也可能整片发黑。

### 把同一个位置交给两条计算链

局部摇摆、角色拨草和世界风动计算完成后，得到 `aRoot + offset`。把它同时用于画面投影，以及传给片元阶段的 `vWorld`：

{{< grass-code demo="grass-shadows" file="grass.vert.glsl" region="animated-position" lang="glsl" >}}

片元阶段读取插值后的 `vWorld`，再使用第二步的光源矩阵和深度比较函数。相机中的叶片与阴影查询点因此一致。

提供这次思路的 Godot 参考实现使用 `skip_vertex_transform`，所以需要显式写入视图空间位置与法线：

```glsl
VERTEX = (VIEW_MATRIX * vec4(aRoot + offset, 1.0)).xyz;
NORMAL = normalize(mat3(VIEW_MATRIX) * normal);
```

网页中使用世界空间的 `vWorld` 做查询，两者的坐标接口不同，但遵守同一个原则：**从实际变形后的顶点出发，不能继续使用未变形的顶点或固定草根。** 此处只改变叶片的接收位置；草叶没有写入深度图，所以无需再做草叶投影用的变形材质。

**观察方式：** 暂停后放大立方体阴影边缘，勾选「错误示例：按草根查阴影」进行对照。也可以保持风动或让小球经过附近，检查草片穿过边界时的明暗变化。关闭风动仍保留小球拨草，两者可分别观察。
{{< grass-step-end >}}

{{< grass-step number="5" title="分段：量化受光，不量化阴影可见度" >}}

**本步新增：卡通分段亮度。** 真实阴影决定光能否到达，风格化函数决定到达的光怎样表现，这两个步骤分开处理。

先计算朝向与光方向的点积，再用与 Godot 参考实现对应的 `bandedDiffuse()` 将连续亮度组织成几档。每个档位之间保留一小段渐变。

{{< grass-code demo="grass-shadows" file="lighting.glsl" region="bands" lang="glsl" >}}

然后把分段结果乘上阴影可见度与直射光强度。关键顺序是：

```text
法线与光方向 → 分段受光亮度
                         × 阴影可见度
                         × 太阳颜色和强度
                         = 直接光照
```

不要先把阴影乘进去，再把整个结果硬分段，否则过滤后的阴影边缘也会被重新切断。在 Godot 参考代码中，对应的是：

```glsl
float diffuse = bandedDiffuse(max(dot(NORMAL, LIGHT), 0.0));
DIFFUSE_LIGHT += diffuse * cloud * ATTENUATION * LIGHT_COLOR / PI;
```

在这里的单个平行光网页场景中，`visibility` 对应遮挡产生的可见度；Godot 的 `ATTENUATION` 是引擎提供的光照衰减，不能泛化为所有灯光下都只有阴影这一项。

**本步不新增纹理。** 仍使用同一张光源深度图，只改变光照组合方式。调节「光照色阶」，或取消「卡通分段」，观察立方体表面和草叶的明暗层次；阴影边缘的过滤应继续存在。
{{< grass-step-end >}}

{{< grass-step number="6" title="暗部：使用环境光，而不是让草自带亮度" >}}

**本步新增：独立可调的环境光。** 前面没有环境光，所以完全遮挡直射光的位置可以变黑；现在加入一份偏冷的环境光，让暗部继续保留草叶颜色与细节。

上一文的演示使用 `0.35 + 0.65 × 光照` 保证暗部可读；这是一条固定最低亮度。这里移除这条下限，改成明确的环境光输入。

{{< grass-code demo="grass-shadows" file="lighting.glsl" region="composition" lang="glsl" >}}

最终组合是：**线性空间的底色 ×（直接光照 + 环境光照）**。环境光不乘立方体的直射阴影遮罩，直接光则会受到物体遮挡与云影影响。结果再转换为屏幕显示颜色，避免直接在显示编码颜色上进行光照相乘。

这里的环境光是统一的近似输入，并没有实现环境遮蔽或完整全局光照。它也不是自发光：`uAmbientEnergy` 为零时，这一项会完整消失。

### 用关灯验证逻辑

1. 关闭「查看阴影遮罩」，确保正在看最终画面。
2. 将直射光设为 0，只保留环境光：草、地面和方块还有颜色，但没有太阳造成的明暗对比。
3. 再把环境光设为 0：所有这些物体应该全黑。
4. 恢复直射光和环境光，观察投影与暗部细节回来。

背景只是展示用的固定颜色，不参与场景光照；检查“关灯全黑”时看的是物体表面，不是要求整张画布连背景一起变黑。本步没有增加环境贴图，环境颜色和强度直接由参数传入。
{{< grass-step-end >}}

{{< grass-step number="7" title="组合：清晰草叶、柔和阴影与独立云影" >}}

**本步新增：云影组合，并开放阴影软边和深度偏移参数。** 至此，风动决定叶片姿态，立方体决定真实遮挡，云层噪声调节大范围直射光，环境光负责暗部。

### 透明轮廓一直保留

草叶使用最近邻采样；透明像素直接丢弃，不输出一块半透明矩形。下面的判断从第一步就启用，而不是到最后才修补：

{{< grass-code demo="grass-shadows" file="grass.frag.glsl" region="silhouette" lang="glsl" >}}

草叶不写入光源深度图，因此不会互相投影。这可以避免密集草片形成大量碎黑斑，同时保留立方体、小球投到草上的阴影。如果以后让草也投影，必须在光源绘制阶段同步草片变形与透明裁切，不能直接把未变形的矩形写进深度图。

### 云影与物体阴影各用一份输入

云影沿用上一文的两层噪声组合，但这次投影方向跟随太阳参数。它不会修改立方体生成的深度图。

{{< grass-code demo="grass-shadows" file="lighting.glsl" region="cloud-light" lang="glsl" >}}

| 输入 | 采样依据 | 影响的结果 |
| --- | --- | --- |
| 草叶／装饰贴图 | 变形后的草叶 UV | 草的轮廓与底色细节 |
| 色块噪声 | 地面位置或草根 XZ | 固定的区域颜色 |
| 风场噪声 | 草根 XZ 与分帧时间 | 叶片旋转和假透视 |
| 光源深度图 | 变形后的真实表面位置 | 立方体、小球造成的遮挡 |
| 云影噪声 | 沿太阳方向投到云层的位置 | 大范围直射光强弱 |
| 环境光参数 | 统一颜色与强度 | 阴影中的基础照明 |

物体阴影与云影在这篇文章中相乘后作用于直射光，环境光单独相加。这与上一文用 `min()` 限制亮度的简化方式不同，对应这次 Godot 参考实现的乘法组合。

### 怎样调软边与偏移

「阴影软边」改变九个比较样本之间的距离。设为 0 时重复比较同一个位置，得到硬边；增大可以看到过滤边缘。它是固定九点 PCF，不是物理面积光源的真实半影，调得过大会出现稀疏采样痕迹。

「深度偏移」用于抵消深度精度和斜面比较误差。太小可能产生表面斑纹，太大会让阴影从物体底部脱开。不要用一个很大的偏移掩盖错误的坐标计算。

{{< grass-code demo="grass-shadows" file="main.js" region="depth-preview" >}}

预览缩小为 256 × 256，并只在展开且可见时刷新；场景查询仍使用完整的 1024 × 1024 纹理。原始深度图是硬深度，软边发生在接收阶段的多次比较中，所以不应该期待预览本身变成一张模糊的影子图片。

**最后的检查：** 改变太阳方向，阴影随之移动；旋转观察相机，阴影仍固定在世界里；暂停后检查草尖穿过边界的状态；关闭所有光照检查物体全黑；最后恢复云影观察完整组合。
